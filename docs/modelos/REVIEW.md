# Revisão — modelo
Escopo: branch/commit base e alvo ou diff local identificado | Data: a preencher
Requisitos e decisões: a vincular

## Achados
Para cada problema: prioridade, arquivo/linha, cenário que o provoca, impacto, evidência e correção sugerida. Separar bug confirmado de dúvida. Não inventar problemas para preencher a lista.
## Verificações
Executadas com resultado; não executadas com motivo; riscos residuais.
## Parecer
Pronto para avaliação humana ou alterações necessárias. Ausência de achados não garante ausência de bugs e não autoriza merge.
